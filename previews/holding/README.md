# mikail.xyz — temporary holding page

Matte dark / liquid-glass-lite **holding page** for [mikail.xyz](https://mikail.xyz) while the full personal-OS desktop release is finished.

This is **not** the OS window-manager site and **not** a Win98 prototype. One quiet screen: name, builder line, a single redesign teaser, and real links (GitHub, email, X, Lab).

## Open locally

```bash
cd mikail-holding
python3 -m http.server 8765
# → http://localhost:8765
```

Or just open `index.html` in a browser (relative assets; works offline aside from the Inter webfont).
