# GUI — OS Desktop Personal Site Bakeoff

Five benchmark **operating-system desktop** personal-site prototypes plus **Win98×XP**, **Classic Windows 98** and **Liquid Glass (macOS + iOS)** iterations for [Mikail](https://github.com/MikailR), each generated by a different CLI/model against the same creative brief.

This is not a portfolio grid contest. The bar: open it on phone or laptop and feel like you’re on a mini OS — wallpaper, icons, windows, dock/taskbar, motion, keyboard shortcuts.

## How to compare

1. Skim [COMPARISON.md](./COMPARISON.md) for a 1–3 sentence critique per direction.
2. Open the [live comparison board](https://mikailr.github.io/GUI/) or jump to a preview above ([live-urls.md](./live-urls.md)).
3. Or run locally from a branch:

```bash
git clone https://github.com/MikailR/GUI.git
cd GUI
git checkout <branch>   # e.g. fable-5.1
npm install
npm run dev
```

## Shared brief (summary)

- Desktop metaphor (Windows or macOS language — pick one and commit)
- Icons → windows; dock/taskbar; rich placeholder content (About, Hackathons, Writing, Lab, Trash…)
- Mobile: full-screen sheets / stacked cards that still feel OS-like
- Delight: glass/acrylic or tasteful skeuomorphism, subtle motion, keyboard shortcuts
- Pure front-end; Vite+React/TS preferred; `npm run build` must succeed

Each branch’s `PROTOTYPE.md` notes model id + visual direction.
