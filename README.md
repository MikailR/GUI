# Helios — Mikail’s personal site

A self-contained OS-desktop prototype. macOS language (menu bar, traffic lights, magnifying dock) with original Helios chrome: ember sun on indigo, Fraunces + Outfit, glass windows.

## Run

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Using the machine

**Desktop**
- Double-click icons to open windows; drag title bars; traffic lights close / minimize / zoom
- Dock: click to open or focus; click a focused app to minimize
- Right-click the desktop for wallpaper / restart
- Spotlight: `⌘ Space` or `Ctrl Space` (also `⌘ K`)
- `Esc` or `⌘ W` closes the focused window · `⌘ \`` cycles · `⌘ 1–8` launches apps

**Mobile**
- Home grid + bottom dock
- Apps open as full-screen sheets with **Done**

Apps: About, Hackathons, Writing, Lab (spring / type / glass), Papers, Terminal (`help`), Settings, Trash.
