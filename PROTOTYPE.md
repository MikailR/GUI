# mikailOS / prototype

**Model:** gpt-6-astra

**Visual direction:** An unhurried, botanical desktop: engraved rolling hills, warm paper windows, olive controls, hand-built SVG objects, and editorial serif typography. A consistent macOS-inspired shell frames a personal space that feels lived in, with a ticking clock, a taped note, and a glass dock.

**Run:** `npm install && npm run dev` (Node 20.19+). `npm run build` produces `dist/`; `npm run preview` serves it. `npm run check` verifies offline rendering.

**Scope:** Six working apps, multiwindow management, desktop drag and resize, mobile app sheets, searchable launcher, keyboard shortcuts, appearance controls, and interactive sample content. Fonts and artwork are bundled. All work is self-contained in this directory.
